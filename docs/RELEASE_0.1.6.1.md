# 0.1.6.1 输出目录提示修正

客户端要求目录名称为 `MabinogiMobile_TW`。工具允许直接输出到这个名称的已存在空目录，也允许填写尚不存在的路径；不会自动添加后缀、改名或清理目录。

使用本机现有目录时：

- 台服来源：`C:\Nexon\Library\MabinogiMobile_TW-back`
- 输出目录：`C:\Nexon\Library\MabinogiMobile_TW`

输出目录必须为空，并与来源目录不同。若已有游戏数据，请先自行将旧目录移到另一个备份名称，再把空目录作为输出。工具不会删除或覆盖旧客户端。

0.1.6本身已经支持已存在空目录；之前的报错是所选目录仍含有游戏文件。0.1.6.1改进选择器和说明：允许新路径、保留指定目录名、显示实际输出路径、非空错误列出实际内容，并在启动资源进程前验证来源和输出关系。

选择名为 `appdata` 的输出路径时，界面明确显示实际输出为其父目录，与资源处理进程的原有行为一致。推荐直接选择游戏根目录。
