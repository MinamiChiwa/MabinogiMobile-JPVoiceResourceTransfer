# 0.1.6 Takeover Implementation Plan

> **For agentic workers:** Apply systematic-debugging, test-driven-development and verification-before-completion. Parallelize disjoint file regions; review the integrated result.

**Goal:** Resolve the four reported deployment, coverage and progress problems and deliver a usable portable Windows build.

**Architecture:** Canonical Python source lives in tools/. A portable console executable dispatches both launcher and resource worker, supporting multiprocessing.freeze_support(). JSON progress events describe explicit stages; coverage reports distinguish source equality from an effective replacement.

**Tech Stack:** Python 3.12, Tkinter, UnityPy 1.25.4, PyInstaller 6.22.2, unittest.

**Spec:** docs/superpowers/specs/2026-10-11-takeover-design.md
