# 0.1.7 语音范围扩展

0.1.6.2 只选中名称含 `_VO_` 或位于 `/voice/` 目录的 AudioClip。逐条比对日服、纯净台服和替换后台服的全部音频后发现，部分带人声的资源因命名不同被漏掉，替换后仍是台服音频。

## 新增选中范围

- 编号台词：`_VO1`、`_VO2` 等，例如 `Q_Opening_A1_40_PortalBreakdown_NaoZWhite_VO1`～`VO4`（Nao 开场）。
- Boss 战斗语音：`_Vox`、`_vox`、`_Vox2`、`_Vox_A` 等（Succubus、Banshee Peaca、HighPriest、Homunculus、Morgant 等）。
- 名称中独立的 `_Voice`。
- 歌曲 `BGM_Sub_Quest_LuaSong`：没有语音标记，但日台人声不同，单独列入。

`VoteResult`、`VoidCut`、`Vocal`、`Voxel` 这类仅以 vo 开头的名称不会被选中。

## 覆盖结果（当前台服客户端）

- 可替换目标：7793 → 8328，全部能找到日服来源，0 项未匹配。
- 新增 535 项中，143 项日台音频不同，会被替换；其余与台服相同。
- 其余日台不同但未选中的对象均为 UI 或过场音效。

## 兼容性

- 语音索引格式升级为 2；工具目录中旧的 `.voice-index-cache` 会被忽略并自动重建。
- 旧版生成的日服扫描缓存因目标集合变化会自动重新扫描。
- 已用旧版替换的台服需要用纯净台服副本重新生成，才能包含新增语音。

## 其他修正

- 便携构建不再把依赖包 `__pycache__` 中的 `.pyc` 复制进 `licenses/`，避免带入构建机路径。

## 验证

121 项回归测试通过（4 项因可选编码器或符号链接权限跳过）。便携 EXE 自检通过，并在纯净台服副本上以 dry-run 确认 8328 个目标全部匹配。0.1.6.2 的完整写入已按资源哈希核对 7793 项全部为日服音频、非语音音频未变；0.1.7 新增目标尚未进行完整写入和游戏内播放验证。

公开包不包含客户端语音或 `resource_cache.bin/json`。
