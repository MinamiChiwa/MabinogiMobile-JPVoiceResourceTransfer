# 0.1.6.2 路径显示修正

Windows文件选择器可能返回 `C:/Nexon/Library/...`。它与 `C:\Nexon\Library\...` 指向相同位置，但旧界面直接显示返回值，导致来源和输出格式不同。

日服、台服和输出三个字段现在统一使用Windows反斜杠格式。浏览选择、手动输入失去焦点以及点击开始时都会规范显示。空的日服字段、盘符根目录、UNC路径和路径内空格保持有效；不会为输出目录追加后缀。

更新0.1.6.1时，先退出工具，再将小更新包直接解压覆盖到原工具目录；保留 `_internal` 子目录层级。更新包仅包含程序、标准库归档和版本信息，不包含游戏语音资源。
