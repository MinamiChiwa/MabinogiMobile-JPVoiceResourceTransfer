MabinogiMobile 日服语音资源转移工具 0.1.5-nojp

一、默认使用方式

1. 完整解压后双击 run_transfer.bat。工具会打开图形界面，并按系统区域显示简体中文、繁體中文或 English；命令行模式可明确选择语言。
2. 必须点击“浏览”选择日服客户端根目录。本版本不含日服语音缓存或 WAV 归档，不能留空。
3. 选择台服游戏根目录，或直接选择其中的 appdata 目录。
4. 选择一个空的输出目录。可以选择尚不存在的新目录，也可以选择已经存在但为空的文件夹；非空目录会被拒绝。不要覆盖原客户端，也不要把输出目录放在原客户端里面。
5. 默认范围是全部 Vo_NPC_Aranwen_（阿蘭雯）语音；选择“全部语音（ALL）”可切换全量。
6. 最大数量填 0（默认）表示处理所选范围内的全部语音。
7. 工具默认使用完整重建模式。窗口会显示当前阶段和进度条，实时输出和错误保存在 run_transfer.log。
8. 运行过程中可以点击“停止”；停止后请不要使用未完成的输出副本，并先查看日志。

命令行用户可运行 `py -3 -X utf8 resource_transfer_launcher.py transfer --cli`；命令行会先让你选择 1 简体中文、2 繁體中文或 3 English。
图形界面中的“赞助作者”按钮会打开二级窗口；赞助完全自愿，不影响工具使用。窗口内提供爱发电（https://afdian.com/a/minamichiwa）和 Patreon（https://www.patreon.com/cw/chiwaminami）两个入口。

工具不会假定任何安装目录。日服和台服源目录只读；工具复制台服客户端后，在新副本中重建受影响的资源包。
输出结构保持为 输出目录\appdata\AssetPackages...，不要把包移动到 appdata 外面。

首次填写日服目录时会扫描日服全部 `.blob`，这是正常现象；之后会在工具目录保存并复用选中目标的扫描缓存。
扫描结束后，工具会在工具目录的 `.jp-scan-cache` 保存本次目标集合对应的压缩资源缓存；
下次使用同一日服版本和同一目标集合会直接复用。日服 manifest 或目标集合变化后缓存自动失效。
工具不会修改日服客户端，也不会把台服输出包写回工具目录；输出只写入你选择的新游戏目录。

二、完整重建做了什么

工具保留日服原始 FSB5 音频，不把语音压缩进台服原资源槽，也不降低采样率。
每个目标 AudioClip 的资源偏移、资源大小、时长、采样率和声道会更新到日服数据。
UnityFS bundle 会重新构建；bundle 变大后，外层 .blob 的累计 bundle 结束偏移表会同步更新。
AssetPackages\index 保持原有 bundle 顺序和数量，因此不需要改写；官方 59826-obd-manifest 也不会被伪造或修改。

同一个角色的语音可能分布在多个 .blob。工具会按所有匹配目标处理相关包体，不要只替换一个编号包。
每个包体和每条目标在写回后都会用 UnityPy 重新读取，目标音频会进行完整 FSB5 解码验证。

三、结果检查

查看输出目录\appdata\patch-report.json：

- transaction_status 为 committed 表示所有选中目标都已提交。
- replacement_mode 为 full-rebuild 表示使用本工具的正式模式。
- committed_count 是实际替换数量；failed 不应出现。
- replacements 中会列出每个目标的源包、目标包、bundle 偏移、原始/新资源大小和校验值。

replacement-summary.txt 适合普通用户快速确认替换名称；client-version.json 记录源客户端版本和清单摘要。
出现 failed、bundle 校验错误、格式错误或写回错误时，退出码为 2，不能把副本当成完成品。

四、测试与恢复

测试前关闭游戏、平台和更新器。确认报告成功后，再把原目录改成备份名，把输出副本改成平台使用的原目录名。
输出副本中的 rollback.ps1 可用于恢复工具创建的备份；更稳妥的做法是直接删除测试副本并恢复原目录名称。

完整重建会改变 .blob 文件大小、bundle 偏移和文件哈希。启动器可能重新下载、修复或拒绝修改后的包，
也可能在地图加载或在线完整性检查时拒绝。不要修改 manifest 来绕过检查；请使用可丢弃的客户端副本和测试账号。
本工具不注入进程，不修改官方 manifest，也不提供反作弊或账号安全保证。

客户端更新后必须重新扫描。新的包布局、Unity 版本或音频格式可能需要重新验证；不要复用旧输出目录继续处理。

五、音频与第三方组件

本版本不随包提供 resource_cache.bin/json 或 WAV 归档；所有日服语音均从你选择的日服客户端读取。
第三方组件和许可证见 THIRD_PARTY_NOTICES.txt。
